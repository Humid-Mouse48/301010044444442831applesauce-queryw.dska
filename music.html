YouTube API key

A built-in key is already set up. You can use your own instead: a free key turns on search and trending. The player uses Piped by default, which does not require an API key to play songs. Create one at Google Cloud Console (enable “YouTube Data API v3”). Without one you can still paste a YouTube link into the search box, or use Starter Picks.

Player source (optional)

The player currently uses cf.piped.video by default. You can paste a different embed address here — put {id} where the video ID goes. To switch back to Piped, leave the box empty and save.
